![Python](https://img.shields.io/badge/Python-3.9+-blue.svg)

> 법률명·지자체·API키만 넣으면, **그 법률에 연결된 지자체 조례·규칙**을 찾아
> 표와 네트워크 그래프로 보여 주는 파이썬 GUI 프로그램입니다.

> 📖 **왜 이걸 만들었나 → [WHY.md](WHY.md)**

「공무원을 위한 AI 활용」 **7-5장 ‘그래프DB로 법령 관계 분석하기’** 의
- 6장 *법령 인용 네트워크 만들기*
- 7장 *나를 인용하는 법 찾기* (“내 법을 인용하는 법은 무엇인가”의 역방향 질의)

개념을 그대로 도구로 옮긴 것입니다. 법제처 **국가법령정보 공동활용 OPEN API** 를 직접 호출합니다.

## 빠른 시작 (3단계)

1. **API 인증키(OC) 발급** — 무료. 아래 *API키 발급* 참고.
2. 실행
   ```bat
   실행.bat        ← 더블클릭
   ```
   또는 터미널에서
   ```bat
   python law_ordinance_network.py
   ```
3. 창에서 **법률명 · 지자체 · API키**를 입력하고 **[🔍 연결 조회]** 클릭.

> 예시: 법률명 `주차장법` / 지자체 `서울특별시 강남구` → 강남구의 주차장법 연계 조례 14건이
> *근거 / 인용 / 관련* 으로 분류되어 표와 그래프로 표시됩니다.

## API 인증키(OC) 발급 — 무료(신청·승인 필요)

인증키(OC)는 법제처 OPEN API에 **활용신청을 하고 승인을 받아야** 발급·사용할 수 있는 값입니다. **임의로 만들 수 없습니다.**

1. [open.law.go.kr](https://open.law.go.kr) 접속 → 회원가입 / 로그인
2. **[OPEN API → 활용신청]** 에서 사용할 API와 활용사례를 등록해 신청
3. 담당자 **승인(보통 1~2일)** 후 사용 가능
4. 승인된 **인증키(OC)** 는 로그인 후 **‘마이페이지 / 신청내역’** 에서 확인

프로그램의 **[API키 발급 안내]** 버튼으로 신청 페이지를 바로 열 수 있습니다.

## 입력 방법

| 칸 | 입력 방법 | 설명 |
|---|---|---|
| 법률명 | 직접 입력 + **[🔎 법령 확인]** | 정식명칭을 모르면 버튼으로 확인·선택 |
| 지자체 | **광역 콤보 + 시·군·구 콤보** | 광역을 고르면 시군구가 자동으로 채워짐 |
| API키 | 직접 입력 | 법제처 OPEN API 인증키(OC) — 활용신청·승인 후 발급 |

### 🔎 법령 확인 기능
법률명을 입력하고 **[🔎 법령 확인]** 을 누르면, 실제 존재하는 법령 후보(법률·시행령·시행규칙)가
**구분·소관부처·공포일**과 함께 표시됩니다. 정확한 법령을 골라 정식명칭을 확정하세요.
확정되면 입력란 옆에 `✓ 확인됨: 주차장법 (법률 · 국토교통부)` 처럼 표시됩니다.
→ 오타·약칭으로 인한 헛검색을 막아 줍니다.

### 🏛 지자체 확인 기능
지자체는 **광역(시·도) → 시·군·구** 2단계로 선택합니다. 광역을 고르면 그 산하 시·군·구가
콤보에 자동으로 채워집니다(전국 17개 시·도, 시·군·구 내장).
- 시·군·구에서 `(전체)` 를 고르면 그 광역 **전체**(산하 시군구 포함)를 봅니다.
- 목록에 없는 경우 시·군·구 칸에 직접 입력해도 됩니다(부분일치 필터).

### 🔁 옛 법령명(제명변경) 자동 확장
법이 개정되며 이름이 바뀐 경우, **옛 이름을 인용하는 조례까지 함께** 찾습니다.
- 예: `지능정보화 기본법`을 조회하면 옛 이름 `국가정보화 기본법`을 인용하는 조례도 검색됩니다.
- 법제처의 `이전법령명` 정보를 자동으로 가져와 **현행명 + 옛 이름**으로 동시 검색하고 합칩니다.
- 옛 이름을 인용하는 조례는 **인용명칭** 칸에 `⚠ 옛이름`으로 표시되고, 하단에 `옛 명칭 인용 N건(정비 대상)`으로 집계됩니다 → 그대로 **조례 정비(개정) 목록**이 됩니다.
- 여러 번 개명됐거나 자동으로 못 잡는 경우 **추가 검색어** 칸에 직접(쉼표로 여러 개) 넣으세요.

> 실제 예) 전라남도 강진군 ‘지역정보화촉진 조례’는 제1조에 아직 「국가정보화 기본법」을 인용합니다.
> 현행명으로만 검색하면 누락되지만, 이 기능으로 ⚠ 정비 대상으로 잡힙니다.

## 결과 보는 법

### 연결강도 (위가 강한 연결)

| 표시 | 색 | 의미 |
|---|---|---|
| **근거(제1조 위임)** | 🟢 초록 | 조례 **제1조(목적)** 에 「법률명」 명시 — 그 법의 위임으로 제정된 조례 |
| **인용(본문)** | 🟠 주황 | 본문 다른 조문에서 그 법을 인용 |
| **관련(간접)** | 🟣 보라 | 본문을 확인했으나 「법률명」 직접 인용은 없음(검색만 매칭) |
| **미검증** | ⚪ 회색 | 본문을 확인하지 않음(‘검증 상위 N건’ 밖) |

- **표** : 행을 **더블클릭**하면 국가법령정보센터 원문이 브라우저로 열립니다. 머리글 클릭으로 정렬됩니다.
- **네트워크 그래프** : 가운데가 법률, 주변이 조례. 화살표(조례 ──인용──▶ 법률)는
  *“나를 인용하는 법”* 의 방향입니다.
- **[CSV 저장]** : 인용 문장까지 포함해 엑셀로 내보냅니다(UTF-8 BOM).

## 동작 원리 (믿을 수 있는 이유)

1. **법령 확인** `target=law` — 입력한 법률의 정식 명칭을 먼저 확인합니다.
2. **본문 인용 검색** `target=ordin, search=2` — 그 법률을 **본문에서 인용하는** 자치법규를 모읍니다.
3. **CoVe 검증(검증의 사슬)** — 검색 결과를 그대로 믿지 않고, 각 조례의 **본문 원문**을 다시 받아
   제1조(목적)에 실제로 「법률명」이 있는지 대조합니다.
   덕분에 단어만 우연히 겹친 조례(예: ‘주차장’만 있고 ‘주차장법’은 없는 조례)는 **‘관련(간접)’으로 강등**됩니다.

> 모든 응답은 **XML + UTF-8** 로 받습니다. (법제처 JSON 응답은 한글이 깨지는 알려진 문제가 있어 사용하지 않음)

## 자주 묻는 질문

**Q. “API 인증키가 올바르지 않습니다”가 떠요.**
A. OC는 법제처 OPEN API **활용신청 후 승인**을 받아야 동작합니다. 아직 승인 전이거나 값이 틀리면 인증 오류가 납니다. 승인된 OC는 open.law.go.kr 로그인 후 **마이페이지 / 신청내역**에서 확인하세요.

**Q. 결과가 0건이에요.**
A. 법률명을 정식 명칭으로 넣었는지(예: `주차장법`), 지자체명이 맞는지 확인하세요.
   그 지자체가 실제로 해당 법 관련 조례를 두지 않았을 수도 있습니다.

**Q. ‘미검증’이 너무 많아요.**
A. 옵션의 **‘검증 상위 N건’** 을 늘리세요(느려짐). 시군구까지 지정하면 대상이 줄어 대부분 검증됩니다.

**Q. 한글이 깨져요.**
A. 프로그램 안에서는 깨지지 않습니다. 콘솔 로그만 깨질 수 있어 동작과 무관합니다.

## 한계 (정직하게)

- 본문 인용 검색은 **그 법을 글자 그대로 인용**한 조례를 찾습니다. 약칭으로만 인용하거나
  시행령·시행규칙만 인용한 경우 일부 누락될 수 있습니다.
- ‘관련(간접)’은 무관이 아니라 **직접 인용이 확인되지 않은 것**입니다. 최종 판단은 원문으로 하세요.
- 전국 단위로 매우 많은 조례가 인용하는 법(예: 일부 기본법)은 **‘최대 표시’ 상한** 안에서만 보여 줍니다.


## 🚀 단일 실행파일(.exe)로 어디서든 실행

Python이 깔려 있지 않은 PC에서도 **exe 파일 하나만 복사**하면 바로 실행됩니다.

- 파일: `dist\법률조례_연결확인기.exe` (약 320 MB — matplotlib·그래프 라이브러리 포함)
- 사용법: **더블클릭**. 첫 실행은 내부 압축 해제로 **20~30초** 걸립니다(두 번째부터는 빠름).
- Python·라이브러리 설치 불필요. **USB·공유폴더에 복사**해 그대로 쓰면 됩니다.
- 인터넷은 조회할 때(법제처 API 호출)만 필요합니다.

### 처음 실행 시 Windows 보안 경고가 뜨면
서명되지 않은 exe라 SmartScreen이 막을 수 있습니다 →
**[추가 정보] → [실행]** 을 누르면 됩니다.

### exe를 다시 만들려면(빌드)
```bat
pip install pyinstaller
pyinstaller --onefile --windowed --name "법률조례_연결확인기" law_ordinance_network.py
```
- `--onefile` 단일 exe · `--windowed` 콘솔창 숨김
- 폴더형 배포가 필요하면 `--onefile` 대신 **`--onedir`** 사용(첫 실행이 더 빠름)
- 결과물은 `dist\`(단일파일) 또는 지정한 폴더에 생성됩니다.
